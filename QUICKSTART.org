* Core Installation [0/4]
** TODO [ ] Backup Existing Configuration
:PROPERTIES:
:CATEGORY: Installation
:END:

If you have an existing StumpWM configuration, back it up:

#+BEGIN_SRC bash
if [ -d ~/.stumpwm.d ]; then
    echo "Backing up existing configuration..."
    mv ~/.stumpwm.d ~/.stumpwm.d.backup.$(date +%Y%m%d-%H%M%S)
    echo "Backup created at ~/.stumpwm.d.backup.$(date +%Y%m%d-%H%M%S)"
else
    echo "No existing configuration found. Proceeding..."
fi
#+END_SRC

** TODO [ ] Set Claude API Key
:PROPERTIES:
:CATEGORY: Installation
:END:

*** Add to shell profile
#+BEGIN_SRC bash
echo 'export CLAUDE_API_KEY="sk-ant-api03-YOUR-KEY-HERE"' >> ~/.bashrc
#+END_SRC

Replace =sk-ant-api03-YOUR-KEY-HERE= with your actual key!

*** Reload shell
#+BEGIN_SRC bash
source ~/.bashrc
#+END_SRC

*** Verify it's set
#+BEGIN_SRC bash
echo $CLAUDE_API_KEY
#+END_SRC

** TODO [ ] Configure X11 Startup
:PROPERTIES:
:CATEGORY: Installation
:END:

Create or edit =~/.xinitrc=:

#+BEGIN_SRC bash
cat > ~/.xinitrc <<'EOF'
#!/bin/sh

# Load X resources
[ -f ~/.Xresources ] && xrdb -merge ~/.Xresources

# Set environment variables
export CLAUDE_API_KEY="sk-ant-api03-YOUR-KEY-HERE"

# Start StumpWM
exec stumpwm
EOF
#+END_SRC

Make it executable:
#+BEGIN_SRC bash
chmod +x ~/.xinitrc
#+END_SRC

** TODO [ ] Configure Emacs Integration
:PROPERTIES:
:CATEGORY: Optional
:END:

Add to =~/.emacs= or =~/.emacs.d/init.el=:

#+BEGIN_SRC elisp
;; Add StumpWM integration modules to load path
(add-to-list 'load-path (expand-file-name "~/.stumpwm.d/emacs"))

;; Load StumpWM control
(require 'stumpctl)

;; Load Claude mode
(require 'claude-mode)

;; Enable Claude mode globally
(global-claude-mode 1)

;; Optional: Set API key if not in environment
;; (setq claude-api-key "sk-ant-api03-...")

;; Optional: Auto-connect to StumpWM on startup
;; (add-hook 'emacs-startup-hook 'stumpctl-connect)
#+END_SRC

Save and restart Emacs.

* Troubleshooting Checklist
** Common Issues

*** "Claude API key not configured"
- [ ] Check: =echo $CLAUDE_API_KEY=
- [ ] Ensure it's in =~/.bashrc=
- [ ] Restart shell: =source ~/.bashrc=
- [ ] Restart StumpWM

*** "curl: command not found"
- [ ] Install: =sudo apt-get install curl=

*** "Swank server failed to start"
- [ ] Install Quicklisp (see Optional Components)
- [ ] Or disable: Set =*swank-auto-start* nil= in =config/core.lisp=

*** "No response from Claude"
- [ ] Check internet connection
- [ ] Verify API key is valid
- [ ] Check =~/.stumpwm.d/stumpwm.log= for errors
- [ ] Test with: =:test-http-client=

*** StumpWM won't start
- [ ] Check =~/.xinitrc= syntax
- [ ] Look for errors: =cat ~/.xsession-errors=
- [ ] Test config: =sbcl --load ~/.stumpwm.d/init.lisp=
