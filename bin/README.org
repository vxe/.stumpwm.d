* Overview

This directory contains the safe file-based eval system for StumpWM.

** Files

- =stumpwm-eval.lisp= - Common Lisp module for StumpWM
- =stumpwm-eval= - Shell script wrapper for easy command-line use

* Installation

** 1. Install the Lisp Module

#+BEGIN_SRC bash
mkdir -p ~/.stumpwm.d/modules
cp stumpwm-eval.lisp ~/.stumpwm.d/modules/
#+END_SRC

** 2. Update StumpWM Config

Add to =~/.stumpwm.d/init.lisp=:

#+BEGIN_SRC lisp
;;;; File-Based Eval Module (for Claude AI integration)
(let ((eval-module (merge-pathnames "modules/stumpwm-eval.lisp"
                                    (stumpwm::data-dir))))
  (when (probe-file eval-module)
    (handler-case
        (progn
          (load eval-module)
          ;; Auto-start the watcher
          (stumpwm::start-eval-watcher))
      (error (e)
        (message (format nil "^1✗ Failed to load eval module: ~A^n" e))))))
#+END_SRC

** 3. Install Shell Script

#+BEGIN_SRC bash
sudo cp stumpwm-eval /usr/local/bin/
sudo chmod +x /usr/local/bin/stumpwm-eval
#+END_SRC

** 4. Restart StumpWM

Log out and log back in, or reload your config.

* Usage

** From Shell

#+BEGIN_SRC bash
# Test the eval system
stumpwm-eval '(+ 1 2)'

# Get current window title
stumpwm-eval '(window-title (current-window))'

# Launch Firefox
stumpwm-eval '(run-or-raise "firefox" '\''(:class "Firefox")'\'')'

# Split window
stumpwm-eval '(hsplit)'

# Get all window titles
stumpwm-eval '(mapcar #'\''window-title (group-windows (current-group)))'
#+END_SRC

** From StumpWM

Commands:
- =C-t ; eval-watcher-start= - Start the eval watcher
- =C-t ; eval-watcher-stop= - Stop the eval watcher
- =C-t ; eval-watcher-status= - Show status
- =C-t ; eval-watcher-show-errors= - View error log

* Troubleshooting

** "Timeout waiting for result"

- Eval watcher not started: =C-t ; eval-watcher-start=
- Check if StumpWM is running: =pgrep stumpwm=

** "Eval system is busy"

- Another eval in progress, wait and retry
- Stale lock clears automatically after 10s

** Errors in eval

Check the error log:

#+BEGIN_SRC bash
cat /tmp/stumpwm-eval-errors.log
#+END_SRC

* Technical Details

- **Poll interval:** 2 seconds
- **Error handling:** 3 layers (outer, processing, eval)
- **Lock timeout:** 10 seconds
- **Max output:** 10KB (truncated with warning)
- **File locations:**
  - Input: =/tmp/stumpwm-eval-input=
  - Output: =/tmp/stumpwm-eval-output=
  - Lock: =/tmp/stumpwm-eval.lock=
  - Errors: =/tmp/stumpwm-eval-errors.log=
