* Directory Structure

#+BEGIN_SRC text
~/.stumpwm.d/              # Main repo (under version control)
├── config.lisp            # Main config file (EDIT THIS ONE!)
├── config -> config.lisp  # Symlink (created by bootstrap)
├── desktop/               # Modular config (alternative approach)
│   ├── core.lisp          # WM behavior, workspaces, settings
│   ├── theme.lisp         # Colors, fonts, appearance
│   ├── commands.lisp      # Custom commands
│   └── keybindings.lisp   # Key mappings
├── init.lisp              # Modular entry point (alternative)
├── modules/               # Claude integration backend
├── lib/                   # Utility libraries
├── emacs/                 # Emacs integration
└── bootstrap.sh           # Fresh install setup script
#+END_SRC

* How It Works

1. *StumpWM* looks for config at =~/.config/stumpwm/config=
2. *Symlink*: =~/.config/stumpwm= → =~/.stumpwm.d=
3. *Symlink*: =~/.stumpwm.d/config= → =config.lisp=
4. *Result*: StumpWM loads =~/.stumpwm.d/config.lisp=

* Modifying Configuration

Edit the main config file:

#+BEGIN_SRC bash
# Edit config (single file - simple approach)
vim ~/.stumpwm.d/config.lisp

# Reload in StumpWM
# Press: C-t ; loadrc
#+END_SRC

*Alternative*: Use the modular approach by editing =desktop/*.lisp= and switching the config symlink to point to =init.lisp= instead of =config.lisp=.

* Key Features

** No White Bars
The config removes all gaps, borders, and frame indicators:
- =*internal-border-width*= = 0
- =*frame-outline-width*= = 0
- =*window-border-style*= = :none
- Focus colors set to black

** Modular Design
- =desktop/= - Settings you'll frequently modify (alternative modular approach)
- =modules/= - Claude integration (rarely touched)
- =lib/= - Utility code (rarely touched)
- =config.lisp= - Main config (simple single-file approach)

** Local Overrides
Create =~/.stumpwm.d/local-config.lisp= for machine-specific settings:
- Not tracked in git (in .gitignore)
- Loaded automatically if present
- Perfect for local paths, API keys, etc.

* Troubleshooting

** Config not loading
#+BEGIN_SRC bash
# Check symlinks
ls -la ~/.config/stumpwm  # Should point to ~/.stumpwm.d
ls -la ~/.stumpwm.d/config  # Should point to config.lisp

# Check logs
journalctl --since "10 min ago" | grep -i stump
#+END_SRC

** After config changes
Some settings need full restart:
#+BEGIN_SRC text
C-t ; restart-soft
#+END_SRC
